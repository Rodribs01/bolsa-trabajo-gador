# Bolsa de Trabajo Departamental Digital

Sistema web (PWA) que conecta a postulantes de Oruro con empresas validadas por el Gobierno Autónomo Departamental de Oruro (G.A.D.OR.), con trazabilidad, transparencia y reportes oficiales.

## Roles

- **SuperAdmin GADOR:** valida empresas y ofertas, administra catálogos y genera reportes.
- **Empresa:** publica ofertas laborales y gestiona a sus postulantes.
- **Postulante:** completa su hoja de vida digital y postula a ofertas.

## Tecnologías

- Backend: NestJS, TypeORM, MySQL 8
- Frontend: Angular, Bootstrap 5
- Aplicación web progresiva (PWA) instalable en el celular
